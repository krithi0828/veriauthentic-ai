Model Card: VeriAuthentic Risk Classifier v1.0

Detailed technical documentation on the machine learning model specifications, signal formulas, evaluation provenance, and system limitations.

1. Intended Use & Target Scope

Intended Use: Decision-support tool for online buyers and brand protection teams to evaluate counterfeit risk signals on marketplace listings.

Out-of-Scope: This model does not inspect physical product hardware in-person or perform visual computer vision on product images. Image uploads are used exclusively for user preview and report attachment.

2. Risk Score Formulation

risk_score = round(P(counterfeit | X) * 100.0, 1)
Risk Tier Thresholds:
  • • Low Risk: 0.0% – 25.0%
  • • Moderate Risk: 25.1% – 50.0%
  • • High Risk: 50.1% – 75.0%
  • • Critical Risk: 75.1% – 100.0%

3. Multi-Signal Specifications

Model-Derived Features:
  • • Price deviation percentage relative to MSRP
  • • Seller credibility composite score
  • • Review rating variance & extreme ratio
  • • TF-IDF description vector weights (max 100)
Heuristic / Database Rules:
  • • SQL lookup in official products registry
  • • Code reuse alert (same code in ≥2 sessions)

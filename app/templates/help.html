Frequently Asked Questions

How is the Authenticity Risk Score calculated?

The score (0 to 100%) is generated by a trained Random Forest classifier that evaluates price deviation, seller account age, rating variance, and TF-IDF text features.

Does the model analyze uploaded images?

No. Product image uploads are for user preview, registry reference, and report attachment only. The ML model evaluates tabular and textual listing features.

What does a Code Reuse Alert mean?

A code reuse alert indicates that the same 12-character authentication code tag has been checked across multiple distinct user sessions, suggesting the physical tag may have been cloned.
